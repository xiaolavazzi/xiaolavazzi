周公博，博士、教授、博士生导师，江苏省高端矿山装备国家级重点实验室（培育建设点）主任、江苏省“六大人才高峰”高层次创新人才团队负责人。现任中国工程机械学会矿山机械分会常务理事、中国机械工程学会设备智能运维分会委员、中国振动工程学会转子动力学专业委员会委员、江苏省仪器仪表学会常务理事。入选国家重大人才工程青年学者、中国科协青年人才托举工程、江苏省333工程中青年领军人才，获全国杰出工程师青年奖、江苏省有突出贡献的中青年专家、江苏省青年科技奖（十大青年科技之星）、全国煤炭青年科技奖等。

主要从事机电装备设计与智能运维、传感器网络、特种环境机器人等方面的研究。主持国家重点研发计划课题、国家自然科学基金面上项目、江苏省杰出青年基金项目等项目。以第一/通讯作者在Inf. Fusion、IEEE Trans. Ind. Inform.等期刊发表论文40余篇。以第一发明人获授权国内外发明专利40余件。获国家技术发明二等奖、国家科技进步二等奖、安徽省科学技术一等奖、江苏省科学技术一等奖、教育部科技进步二等奖等奖励。
